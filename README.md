A program that writes one short text to `/output/entry.txt`: a quiet library mystery, written to intrigue the AI judge reading it. Every Friday for a year, the same library book has come back on time, a different flower pressed between the same two pages — and today the flower is one the librarian has never seen before, still warm from the sun.

## Run it

```sh
python3 main.py
```
